Entry for make.fun's ["Monday, Reviewed in One Line"](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) bounty: the funniest one-line review of a Monday, judged pairwise by the house judge.

## Run it

```sh
python3 main.py
```

The program writes the review to `/output/entry.txt` (one line, 126 characters, UTF-8).
